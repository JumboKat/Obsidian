These are what store data.
- **int**: integers (min 16 bits, for values < 32767)
	- other formats: **long int**, **short int**, **unsigned int**, etc.
- **float**, **double**, and **long double**: floating point numbers
- **char**: characters
- **bool**: boolean (true or false)
	- 0 = false, any non-zero integer is 'truthy'
- Special types: sizes of arrays, strings of characters, objects, etc.
